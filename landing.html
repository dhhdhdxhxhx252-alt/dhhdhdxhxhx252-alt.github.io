Возможности

Два режима работы

Простой технический интерфейс для тренировки — и кастомный workflow-редактор нодами, если хочешь собрать свой пайплайн.

Датасет в один клик

Перетащи фото — они уйдут в репозиторий одним коммитом через Git Data API.

Препроцессинг на Actions

Дедуп по md5, кроп по лицу, BLIP-подписи и миниатюры — всё на раннере.

Обучение LoRA

SD 1.5, кэш латентов, min-SNR γ=5, Adafactor, авточекпоинты и превью с фиксированным seed.

Прогресс в реальном времени

state.json и логи публикуются в main каждые 2 минуты — интерфейс живой.

Готовая модель где угодно

Ветка models, GitHub Release и автосохранение на HuggingFace.

Workflow-редактор

Второй режим: кастомные пайплайны нодами — как n8n, но для твоих тренировок.
